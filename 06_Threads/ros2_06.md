06_多线程学习

常用
头文件
```cpp
#include<thread>
#include<mutex>
```

普通创建线程方式
std::thread thread1(函数,参数1,参数2,...);
类内创建线程方式
std::thread thread1(函数,this,参数1,参数2,...);

join();作用是等待该线程执行完。
thread1.join();

引用为参数的时候thread中要传引用参数
```cpp
#include<iostream>
#include<thread>

void foo(int &x)
{
    x+=1;
}

int main()
{
    int a=1;
    std::thread t(foo,std::ref(a));//常用std::ref(x)获取引用
    t.join();
    std::cout<<a<<std::endl;
    return 0;
}
```


类内使用thread需要&+类内函数
```cpp
#include<iostream>
#include<thread>

class A
{
public:
    void foo()
    {
        std::cout<<"Hello"<<std::endl;
    }
};

int main()
{
    std::shared_ptr<A> a = std::make_shared<A>();
    std::thread t(&A::foo,a);//注意&
    t.join();
    return 0;
}
```

std::mutex mtx;创建一个锁。
mtx.lock();加锁。
mtx.unlock();解锁。
加锁后其他线程不能访问锁内代码。
```cpp
int shared_data = 1;
std::mutex mtx;
void func()
{
    for(int i=0;i<10000;i++)
    {
        mtx.lock();
        shared_data++;
        mtx.unlock();
    }
}
```

lock_guard;自动加锁解锁。
std::lock_guard对象不能复制或移动，一般只在局部作用域内使用。
```cpp
int shared_data = 1;
std::mutex mtx;
void func()
{
    for(int i=0;i<10000;i++)
    {
        std::lock_guard<std::mutex> lg(mtx);
        shared_data++;
    }
}
```
