05_c++特性(c++_11版本)

1、自动类型推导。
```cpp
auto node = std::make_shared<rclcpp::Node>("cpp_node");
```
其中auto为自动推导，用于自动推导node的类型。

2、智能指针中的共享指针。
头文件。
```cpp
#include<memory>
```
如
```cpp
auto p1 = std::make_shared<std::string>("hello");
//std::make_shared<数据类型/类>(参数)
//返回值，对应类的指针 std::shared_ptr<std::string> 写成 auto
```
引用计数获取p1->use_count();指向内存地址获取p1->get();指向内存地址数据p1->c_str();
如果p1.reset()，p1会变成空智能指针，引用计数永远为0，指向内存地址nullptr。

3、Lambda。
头文件。
```cpp
#include<algorithm>
```
语法。
```cpp
//[capture list](parameters) -> return_type { function body }
//[捕获参数列表](函数参数列表) -> 返回值类型 {函数体}
```
例子：
```cpp
#include<iostream>
#include<algorithm>
int main()
{
    auto add = [](int a, int b) -> int
    { return a+b; }
    int sum = add[200,50];
    auto print_sum = [sum]() -> void
    {
        std::cout << sum << std::endl;
    }
    print_sum();
    return 0;
}
```
运行例子需要在CMakeLists.txt中添加相应语句。

4、函数包装器。
统一自由函数、成员函数、Lambda函数。
头文件
```cpp
#include<functinoal>
```
例子：
```cpp
#include<iostream>
#include<functional>

//自由函数
void save_with_free_fun(const std::string &file_name)
{
    std::cout<<file_name<<std::endl;
}

//成员函数
class FileSave
{
private:
    /* data */
public:
    FileSave(/* data */)=default;
    ~FileSave() = default;

    void save_with_member_fun(const std::string &file_name)
    {
        std::cout<<"成员方法："<<file_name<<std::endl;
    }
}

int main()
{
    FileSave file_save;

    //Lambda函数
    auto save_with_lambda_fun = [](const std::string &file_name) -> void
    {
        std::cout<<"Lambda函数："<<file_name<<std::endl;
    }

    //save_with_free_fun("file.txt");
    //file_save.save_with_member_fun("file.txt");//这里需要file_save，统一后不需要，安全
    //save_with_lambda_fun("file.txt");

    std::function<void(const std::string&)> save1 = save_with_free_fun;
    std::function<void(const std::string&)> save2 = save_with_lambda_fun;
    //成员函数：放入包装器
    std::function<void(const std::string&)> save3 = std::bind(&FileSave::save_with_member_fun,&
    file_save,std::placeholders::_1);
    /*
    std::bind进行二次绑定，std::bind(类对应函数指针,类对象指针,占位符数量)。
    */

    save1("file.txt");
    save2("file.txt");
    save3("file.txt");
    //统一调用。

    return 0;
}
```
