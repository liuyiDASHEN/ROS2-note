03_独立工作区Work_Space

以chapt2为例子。

1、在chapt2中创建workspace。

cd到chapt2，输入"mkdir -p chapt2_ws/src"。(其中-p为递归，用于自动创建多层嵌套目录，只用mkdir只能创建一层文件夹)



2、迁移。

cd到chapt2，输入"mv demo_cpp_pkg/ chapt2_ws/src/"。(其中demo_cpp_pkg/中的/用于指定移动文件夹。后面的chapt2_ws/src/的/指定src文件夹，如果不带，写成chapt2_ws/src，会让shell先判断src是不是目录，如果没有文件夹src就会把demo_cpp_pkg重命名为src，/起保护作用)



3、清除chapt2原有产物。

cd到chapt2，输入"rm -rf build/ install/ log/"。



4、在工作空间中构建。

(1)如果需要一次性构建全部pkg：先cd到chapt2_ws，输入"colcon build"。

(2)如果只想构建指定的pkg：输入"colcon build --packages-select 功能包名称"。

可跳到6继续。



5、依赖关系。

可以在package.xml文件的package format="3"中增加

```
<depend>rclcpp</depend>
<depend>cpp_node_pkg</depend>
```

确保先构建依赖cpp_node_pkg。



6、完成4之后，每次打开终端都需要source，可输入"source install/setup.bash"，需要确保之前的CMakeLists.txt中有install那几行代码。



7、用功能包运行节点。

cd到chapt5_ws中，输入"ros2 run cpp_node_pkg cpp_node"即可运行cpp_node节点。
