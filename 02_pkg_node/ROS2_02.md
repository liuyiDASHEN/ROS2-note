02_节点与功能包组织。



1、尝试创建c++节点，并在cmake中配置头文件与库文件。(此时未安装C/C++ Extension Pack，未配置独立工作区)

(1)尝试创建c++节点。

可以创建文件夹chapt2，在文件夹内创建文件ros_cpp_node.cpp。

```clike
#include"rclcpp/rclcpp.hpp"
int main(int argc, char** argv)
{
    rclcpp::init(argc, argv);
    auto node = std::make_shared<rclcpp::Node>("ros_cpp_node");
    RCLCPP_INFO(node->get_logger(), "你好，c++节点！");
    rclcpp::spin(node);
    rclcpp:shutdown();
    return 0;
}
```

(2)尝试在chapt2文件夹内配置CMakeLists.txt，引入头文件与依赖库。

```cmake
cmake_minimum_required(VERSION 3.8)
project(ros_cpp_node)
addexecutable(ros_cpp_node ros_cpp_node.cpp)
find_package(rclcpp REQUIRED) #直接找到对应的头文件与库文件
# message(STATUS ${rclcpp_INCLUDE_DIRS})
# message(STATUS ${rclcpp_LIBRARIES})
target_include_directories(ros_cpp_node PUBLIC ${rclcpp_INCLUDE_DIRS}) #头文件包含
target_link_libraries(ros_cpp_node ${rclcpp_LIBRARIES}) #库文件链接
```

(3)cd到chapt2，输入"camke ."，再输入"make"，再输入"./ros_cpp_node"即可运行c++节点。

(4)可以打开另一个终端输入"ros2 node list"查看节点是否成功运行。

(5)安装c++扩展插件。将CMakeLists.txt改为CMakeLists.txt.back备份，以便后续配置。



2、在C/C++ Extension Pack中配置cmake。

安装C/C++ Extension Pack且未配置好C/C++ Extension Pack的cmake时，ros_cpp_node.cpp源码中头文件会变红，此时点击"黄色小灯泡"(没有就重新加载一下或者参照下文修改方法)，选择编辑includePath设置，在包含路径中输入

```
${workspaceFolder}/**
/opt/ros/humble/include/**
```

(修改方法：如果后续想修改includePath，可以使用快捷键ctrl+shift+p，输入"C/C++: Edit Configurations (UI)"，然后即可进入intellisense配置界面。配置好后会在.vscode里面生成c_cpp_properties.json。如果后续不想再配置了，可以直接在另外的工作目录粘贴原有的.vscode文件夹。)



3、安装功能包并组织节点。

(1)安装功能包。

进入chapt2中，输入指令

```
ros2 pkg create --build-type ament_cmake --license Apache-2.0 demo_cpp_pkg
```

(2)创建新的c++节点cpp_node.cpp。

安装功能包后会产生demo_cpp_pkg，cd进入src，输入"touch cpp_node.cpp"创建新的文件，进入该文件输入源码：

```clike
#include"rclcpp/rclcpp.hpp"
int main(int argc, char** argv)
{
    rclcpp::init(argc, argv);
    auto node = std::make_shared<rclcpp::Node>("cpp_node");
    RCLCPP_INFO(node->get_logger(), "你好，c++节点！");
    rclcpp::spin(node);
    rclcpp::shutdown();
    return 0;
}
```

(3)在demo_cpp_pkg中的CMakeList.txt中配置，增加一些新代码。默认代码如下

```cmake
cmake_minimum_required(VERSION 3.8)
project(demo_cpp_pkg)

if(CMAKE_COMPILER_IS_GNUCXX OR CMAKE_CXX_COMPILER_ID MATCHES "Clang")
  add_compile_options(-Wall -Wextra -Wpedantic)
endif()

# find dependencies
find_package(ament_cmake REQUIRED)
# uncomment the following section in order to fill in
# further dependencies manually.
# find_package(<dependency> REQUIRED)

if(BUILD_TESTING)
  find_package(ament_lint_auto REQUIRED)
  # the following line skips the linter which checks for copyrights
  # comment the line when a copyright and license is added to all source files
  set(ament_cmake_copyright_FOUND TRUE)
  # the following line skips cpplint (only works in a git repo)
  # comment the line when this package is in a git repo and when
  # a copyright and license is added to all source files
  set(ament_cmake_cpplint_FOUND TRUE)
  ament_lint_auto_find_test_dependencies()
endif()

ament_package()
```

可以在find_package处下方增加一些代码，添加后如下：

```cmake
cmake_minimum_required(VERSION 3.8)
project(demo_cpp_pkg)

if(CMAKE_COMPILER_IS_GNUCXX OR CMAKE_CXX_COMPILER_ID MATCHES "Clang")
  add_compile_options(-Wall -Wextra -Wpedantic)
endif()

# find dependencies
find_package(ament_cmake REQUIRED)
find_package(rclcpp REQUIRED) #此处查找rclcpp所需头文件与库文件
# uncomment the following section in order to fill in
# further dependencies manually.
# find_package(<dependency> REQUIRED)
add_executable(cpp_node src/cpp_node.cpp) #需要增加src/
# target_include_directories(ros_cpp_node PUBLIC ${rclcpp_INCLUDE_DIRS}) #头文件包含
# target_link_libraries(ros_cpp_node ${rclcpp_LIBRARIES}) #库文件链接
# 以上两个target可简化为如下ament代码
ament_target_dependencies(cpp_node rclcpp)
install(TARGETS cpp_node
  DESTINATION lib/${PROJECT_NAME}
)

if(BUILD_TESTING)
  find_package(ament_lint_auto REQUIRED)
  # the following line skips the linter which checks for copyrights
  # comment the line when a copyright and license is added to all source files
  set(ament_cmake_copyright_FOUND TRUE)
  # the following line skips cpplint (only works in a git repo)
  # comment the line when this package is in a git repo and when
  # a copyright and license is added to all source files
  set(ament_cmake_cpplint_FOUND TRUE)
  ament_lint_auto_find_test_dependencies()
endif()

ament_package()
```

主要添加了：

```cmake
find_package(rclcpp REQUIRED)

add_executable(cpp_node src/cpp_node.cpp)

ament_target_dependencies(cpp_node rclcpp)

install(TARGETS cpp_node
  DESTINATION lib/${PROJECT_NAME}
)
```

(4)创建一个build用于储存cmake的文件，方便清除。

可以cd到chapt2/demo_cpp_pkg，然后输入"mkdir build"，cd到build，然后输入"cmake .."(..表示上级文件夹，.表示当前文件夹)，然后再输入make即可构建。

(5)运行节点。在build中输入ls可查看当前文件夹下内容，其中会有一个绿色名称的cpp_node，可以输入./cpp_node运行测试。



4、添加声明用于工作空间构建。

进入demo_cpp_pkg，打开package.xml。在默认的代码中增加声明。

默认代码

```markup
<package format="3">
  <name>demo_cpp_pkg</name>
  <version>0.0.0</version>
  <description>TODO: Package description</description>
  <maintainer email="jian233@todo.todo">jian233</maintainer>
  <license>Apache-2.0</license>

  <buildtool_depend>ament_cmake</buildtool_depend>

  <test_depend>ament_lint_auto</test_depend>
  <test_depend>ament_lint_common</test_depend>

  <export>
    <build_type>ament_cmake</build_type>
  </export>
```

可以在package format="3"内增加代码

```
<depend>rclcpp</depend>
```

增加后如下

```markup
<package format="3">
  <name>demo_cpp_pkg</name>
  <version>0.0.0</version>
  <description>TODO: Package description</description>
  <maintainer email="jian233@todo.todo">jian233</maintainer>
  <license>Apache-2.0</license>
  
  <depend>rclcpp</depend>
  <buildtool_depend>ament_cmake</buildtool_depend>

  <test_depend>ament_lint_auto</test_depend>
  <test_depend>ament_lint_common</test_depend>

  <export>
    <build_type>ament_cmake</build_type>
  </export>
```
