07_话题通信

1、构建流程
ros2 pkg create xxx_pkg --build-type ament_cmake --dependencies rclcpp (std_msgs base_interfaces_demo) --node-name xxx
(在includepath那里加/opt/ros/humble/include/**)
增加cpp文件时要加add_executable、ament_target_dependencies、INSTALL。

2、写代码。
2-1
代码分为publisher.cpp和subscription.cpp两部分。
2-2
需要创建发布者节点和订阅者节点，以及回调函数。
2-3
每个cpp文件的main中需要auto node = std::make_shared<类名>();rclcpp::spin(node)。
2-4
详情可看else文件夹中instruction.md的常用指令。


3、colcon build后正常会生成install文件，可输入source install/setup.bash，然后再用ros2 run 包名 节点名。

4、自定义接口消息配置。
4-1
功能包下创建msg文件件，文件夹内创建.msg文件，比如Student.msg
```
string name
int32 age
float64 height
```
4-2
编辑配置文件。
(1)package.xml，需要增加代码。
```
<!-- 编译依赖 -->
<build_depend>rosidl_default_generators</build_depend>
<!-- 执行依赖 -->
<exec_depend>rosidl_default_runtime</exec_depend>
<!-- 声明当前包所属的功能包组 -->
<member_of_group>rosidl_interface_packages</member_of_group>
```
(2)CMakeLists.txt，需要增加代码。
```
find_package(rosidl_default_generators REQUIRED)

# 为接口文件生成源码
rosidl_generator_interfaces(${PROJECT_NAME}
    "msg/Studeng.msg"
)
```
4-3
进入工作空间，编译功能包。
colcon build --packages-select 功能包
4-4
测试。
. install/setup.bash
ros2 interface show 功能包/msg/Student.msg
